# ML Assignment 2 — Classification Models & Streamlit Deployment

## a. Problem Statement
Predict whether a telecom customer will churn (cancel their subscription)
based on their account and service usage attributes. This is a binary
classification problem.

## b. Dataset Description
- **Name:** Telco Customer Churn
- **Source:** https://www.kaggle.com/datasets/blastchar/telco-customer-churn
- **Instances:** 7,043 customers
- **Features:** 19 (after dropping the customer ID identifier column)
- **Target:** `Churn` (Yes/No)
- Features include: tenure, contract type, payment method, monthly charges,
  total charges, internet service type, and various add-on services
  (online security, tech support, streaming, etc.)
